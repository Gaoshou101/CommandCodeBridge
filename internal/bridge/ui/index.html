开始使用

先添加 CommandCode 凭据，再获取模型并保存映射。客户端使用 CPA 的 API 地址和客户端密钥。



凭据与套餐用量
按优先级调度账号，查看余额和额度窗口。
相同账号的多把密钥可能共享额度。查询失败会保留上次数据；额度窗口与订阅到期时间分别显示。


模型映射
设置客户端名称和思考强度，测试账号是否可用。
公开目录包含的模型不代表账号拥有调用权限。模型测试会使用所选凭据的少量额度。


请求日志
查看实际账号、响应时间、token 用量与错误详情。


请求与日志设置
调整超时、查询频率和数据保留。
启用后，上游没有可用零数据保留路由时请求会失败。
数据保存
凭据由 CPA 的凭据目录保存。插件目录需要持久化设置、请求日志和统计；清空统计会保留恢复副本。




验证管理登录
直连 CPA 使用管理密钥；经 CPAMP 完整模式访问时，使用面板管理密钥。


添加凭据
数值越大越优先。编辑时留空密钥可保留现有密钥。


编辑模型
例如 {"medium":"high","unset":"low"}。unset 表示未设置。没有命中的强度继续透传。


导入上游模型
选择要添加的模型；已有映射和思考设置会保留。


测试模型
发送简短测试消息，最多生成 256 tokens；使用模型映射和所选账号。
